# 🚀 Деплой приложения на Vercel через GitHub

## Шаг 1: Загрузить код на GitHub

### Если у вас еще нет репозитория:

1. Откройте терминал в папке проекта
2. Выполните команды:

```bash
# Инициализация Git (если еще не инициализирован)
git init

# Добавление всех файлов
git add .

# Первый коммит
git commit -m "Initial commit - Fix auth panel"

# Создание репозитория на GitHub (вручную)
# 1. Зайдите на https://github.com/new
# 2. Создайте новый репозиторий (например: life-balance-app)
# 3. Не добавляйте README, .gitignore или лицензию

# Привязка удаленного репозитория
git remote add origin https://github.com/ВАШ_НИК/life-balance-app.git

# Отправка кода на GitHub
git branch -M main
git push -u origin main
```

### Если репозиторий уже существует:

```bash
git add .
git commit -m "Fix auth panel buttons and guest mode"
git push origin main
```

---

## Шаг 2: Подключение Vercel

1. **Зайдите на [vercel.com](https://vercel.com)**
2. **Войдите через GitHub**
3. **Нажмите "Add New Project"**
4. **Импортируйте ваш репозиторий:**
   - Выберите "Import Git Repository"
   - Найдите ваш репозиторий (например: life-balance-app)
   - Нажмите "Import"

5. **Настройте проект:**
   - **Framework Preset:** Other
   - **Root Directory:** `./` (оставьте по умолчанию)
   - **Build Command:** оставьте пустым
   - **Output Directory:** `public`

6. **Нажмите "Deploy"**

---

## Шаг 3: Проверка работы

После деплоя Vercel предоставит вам ссылку вида:
```
https://life-balance-app.vercel.app
```

### Что проверить:

1. ✅ **Кнопка "Регистрация"** - при нажатии должна:
   - Подсвечиваться синим цветом
   - Показывать форму регистрации (3 поля: Email, Пароль, Повторите пароль)

2. ✅ **Кнопка "Вход"** - при нажатии должна:
   - Подсвечиваться синим цветом
   - Показывать форму входа (2 поля: Email, Пароль)

3. ✅ **Кнопка "Гостевой режим"** - при нажатии должна:
   - Открывать приложение без авторизации

4. ✅ **Форма входа** - после ввода данных и нажатия "Войти":
   - Должна открываться главная страница приложения

5. ✅ **Форма регистрации** - после ввода данных и нажатия "Зарегистрироваться":
   - Должна сразу открывать главную страницу приложения

## Обновление после изменений

После каждого изменения в коде:

```bash
git add .
git commit -m "Описание изменений"
git push origin main
```

Vercel автоматически обновит приложение в течение 1-2 минут.

## Настройка Supabase (опционально)

Если хотите использовать Supabase для синхронизации данных:

1. В Vercel перейдите в Settings → Environment Variables
2. Добавьте переменные:
   - `SUPABASE_URL` = ваш URL из Supabase
   - `SUPABASE_ANON_KEY` = ваш anon key из Supabase
3. Нажмите "Save"
4. Сделайте новый деплой
