# 🚀 Деплой на Vercel

## Быстрый старт

### 1. Отправьте код на GitHub

```bash
# Проверка статуса
git status

# Добавление всех изменений
git add .

# Коммит
git commit -m "Update: Simple auth with guest mode"

# Отправка на GitHub
git push origin main
```

### 2. Подключите репозиторий к Vercel

1. Зайдите на [vercel.com](https://vercel.com)
2. Войдите через GitHub
3. Нажмите **"Add New Project"**
4. Выберите ваш репозиторий из списка
5. Нажмите **"Deploy"**

### 3. Настройте переменные окружения (опционально)

Если хотите использовать Supabase для синхронизации данных:

1. В Vercel Dashboard перейдите в **Settings** → **Environment Variables**
2. Добавьте переменные:
   - `SUPABASE_URL` = `https://xhzscskvrxefnoardxxa.supabase.co`
   - `SUPABASE_ANON_KEY` = `sb_publishable_w2dp-1spX0B65wbdlt6jtQ_OAZPsARd`
3. Нажмите **Save**
4. Сделайте новый деплой (Vercel автоматически обновит)

### 4. Проверьте работу

После деплоя Vercel предоставит ссылку вида:
```
https://ваш-проект.vercel.app
```

Откройте приложение и проверьте:
- ✅ Форма входа/регистрации работает
- ✅ Кнопка "Продолжить без аккаунта" работает
- ✅ Данные сохраняются (в гостевом режиме - локально)

После каждого изменения:

```bash
git add .
git commit -m "Описание изменений"
git push origin main
```

Vercel автоматически обновит приложение в течение 1-2 минут.

## Важно

### Гостевой режим
- Данные хранятся **только в браузере** пользователя
- При очистке кэша или выходе данные **теряются**
- Нет синхронизации между устройствами

### Email авторизация
- Работает **локально** (без серверной аутентификации)
- Данные сохраняются в localStorage
- При желании можно подключить Supabase Auth

### Supabase (опционально)
- Если добавите переменные окружения, данные будут синхронизироваться
- Без переменных - работает in-memory база данных
