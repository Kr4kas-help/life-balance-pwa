# Баланс Жизни - PWA Приложение

Приложение для продуктивности и самосовершенствования с офлайн-поддержкой.

## 🔐 Авторизация

Приложение поддерживает два способа входа:
- **Гостевой режим** - локальное хранение данных без синхронизации
- **Email/пароль** - локальная авторизация (данные сохраняются в браузере)

## Функции

- 📊 Dashboard с прогрессом
- 📖 Отслеживание чтения книг
- 💧 Счётчик воды
- 🧘 Таймеры (Pomodoro, разминка)
- 📚 Изучение новых слов
- 🙏 Дневник благодарности
- 🎯 Икигай тест
- 📅 Календарь жизни
- 🗺️ Отслеживание прогулок
- 🏆 Достижения
- 💊 Бады и витамины

## Технологии

- Frontend: HTML5, CSS3, JavaScript (ES6+)
- PWA: Service Worker, Manifest
- Backend: Node.js + Express
- База данных: Supabase (или встроенная in-memory)

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

## Деплой на Vercel

1. Создайте аккаунт на [vercel.com](https://vercel.com)
2. Установите Vercel CLI: `npm i -g vercel`
3. Запустите: `vercel`
4. Следуйте инструкциям

## Переменные окружения (опционально)

```
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
```

Без переменных окружения приложение работает с in-memory базой данных.
